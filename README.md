# Neural-Network-three-layers-

## 概要
入力層、中間層、出力層の３層で構成される簡易的なニューラルネットワークを実装した。  
中間層の活性化関数はrelu関数で、出力層はsoftmax関数を採用している。  
重さの更新にはadamを採用している。  
誤差関数の勾配の計算には誤差逆伝搬法で出力層の方から計算している。 

現在は、0~9のうち一つの数字がかいてある画像を入力し、学習させている。  
学習ごとに誤差を計算し、誤差が小さくなっていく過程をプロットしている。

### パラメータ(adam)
- beta1: 0.9
- beta2: 0.999
- learning_rate = 0.001
- eps = 10 ** -8

## 実行方法
srcフォルダ内で実行  
python nn.py

## 考察
結果では、stepが50回弱ぐらい以降大きな変化は見られなくなっている。今回は0~9の数字を分類するため出力層が10個あるので、
思っていたよりも誤差の収束が速く感じた。原因として、200個の訓練データとして使用している10個の数字の画像がすべて同じであることが考えられる。  
試しに学習後の重みで手書きの数字0を入力し確率を計算したところ、以下の結果になった。  
- 数字0： 0.1007(10.07%)
- 数字1： 0.0972(9.72%)
- 数字2： 0.1017(10.17%)
- 数字3： 0.1017(10.17%)
- 数字4： 0.0991(9.91%)
- 数字5： 0.1006(10.06%)
- 数字6： 0.1007(10.07%)
- 数字7： 0.0988(9.88%)
- 数字8： 0.0995(9.95%)
- 数字9： 0.1000(10.00%)

学習データと違う手書きの数では全く確率を計算で来ていなかったため、訓練データは様々なパターンが必要だと分かった。

## 動機・感想
現在講義内でパターン認識という講義を受けており、その中でニューラルネットワークの仕組みについて学んだ。　　
仕組みは思っていたより単純で、出力結果と実際の結果から誤差を計算し、層の間の重みごとに勾配を計算して、  
繰り返し更新していくというものだった。  
実際に自分で学習の過程を見る機会はあまりないため、新鮮で面白かった。  
最初、仕組みが完成した時点である数字を読み込ませ学習させ、もう一度同じ数字の確率を出力させたとき、  
最初の確率は重みの初期値がランダムであるため8~12%ぐらいだったが、学習後は90%ぐらいまで確率が上がっており、  
重みの更新による学習効果を実感した。  
コードに関しては、pythonをこれまであまり触ったことがなかったためコードの勉強から始めた。  
特殊なfor文や三項演算子もすぐに慣れたが、行列計算だけはあまりなれず、AIを使用して簡潔にした。  
行列計算をコードにするのにはなれるのに時間がかかりそうな気がする。
